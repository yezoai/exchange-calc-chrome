# Exchange Calc Chrome

一个用于快速换算价格的 Chrome 扩展。用户选中网页中的金额后，可以直接在右键菜单中看到人民币、美元、卢布的换算结果；点击菜单项后，会把完整结果复制到剪贴板。

## 当前功能

- 识别常见金额格式
  - `¥2`
  - `$2.15`
  - `₽300`
  - `CNY 12`
  - `USD 5.5`
  - `RUB 300`
  - `2.15`（默认按 `CNY` 处理）
- 右键菜单动态显示换算结果
- 点击菜单项后复制完整换算文本
- 浏览器工具栏弹窗支持手动输入或读取当前选中内容
- 汇率本地缓存 1 小时，接口失败时优先回退到缓存

## 项目结构

- `manifest.json`
  Chrome Extension Manifest V3 配置
- `background.js`
  右键菜单注册、菜单标题更新、复制结果、通知反馈
- `content.js`
  监听页面选中内容变化，提前通知后台刷新菜单标题
- `popup.html` / `popup.js`
  工具栏弹窗，用于调试和常驻换算入口
- `options.html` / `options.js`
  设置页，用于配置默认币种和汇率缓存时长
- `src/parser.js`
  金额解析和币种识别
- `src/rates.js`
  汇率获取、缓存和换算
- `src/settings.js`
  扩展设置的读取、归一化和持久化
- `src/formatter.js`
  结果文本格式化
- `test-page.html`
  本地测试页
- `icons/`
  扩展图标（16 / 32 / 48 / 128）
- `scripts/make_icons.py`
  图标生成脚本（依赖 Pillow）

## 本地使用

1. 打开 `chrome://extensions`
2. 开启“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 选择当前目录
5. 打开任意网页或本地测试页，选中金额后右键测试

## 设置页

在扩展详情页中打开“扩展程序选项”，或在扩展管理页进入设置页，可配置：

- 纯数字默认币种
- 汇率缓存时长

## 本地测试页

可直接打开：

- `test-page.html`

或者在项目根目录启动本地服务：

```bash
python3 -m http.server 4173
```

然后访问：

- `http://localhost:4173/test-page.html`

## 已验证行为

- 右键菜单可以显示换算后的 `CNY / USD / RUB`
- 点击菜单项后可复制完整结果
- 弹窗模式下可以手动输入金额进行换算

## 已知限制

- 当前只支持 `CNY / USD / RUB`
- 纯数字默认按 `CNY` 处理
- 暂不支持负数、区间价格、后缀货币格式，例如 `5 USD`
- 右键菜单标题长度受 Chrome 限制，长结果会截断显示
